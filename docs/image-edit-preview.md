# Предпросмотр запросов клининга и восстановления

Переключатель **Настройки → Конвейер → Предпросмотр перед отправкой в API** включает проверку каждого запроса к Fal, OpenRouter или Replicate. Локальные модели работают без этого окна.

Окно показывает страницу, провайдера, модель, размер и изображение запроса. Промпт можно изменить или вернуть к исходному. Изменения относятся только к этой отправке и не переписывают настройки. Кнопка «Отправить» продолжает запрос, отмена останавливает текущую обработку. При обработке главы предпросмотр появляется отдельно перед каждым запросом.

## Что объединяется

| Действие | Изображение для модели |
| --- | --- |
| API-клининг страницы | Исходник + видимые слои рисунка кистью (Paint). Предыдущие слои клининга (Cleanup) исключены. |
| Инструмент «Восстановление» | Исходник + видимые Cleanup и Paint в порядке слоёв. Полученное изображение обрезается до выделенного прямоугольника. |
| Локальная кисть «Удаление» (LaMa и другие локальные модели) | Исходник + все видимые Cleanup и Paint в порядке слоёв, с их прозрачностью и видимостью родительских групп. Предпросмотр API не применяется. |

В API-композиции учитываются видимость, прозрачность и альфа-канал растровых слоёв. Текст перевода, область OCR, маски и рамки инструментов не рисуются в отправляемое изображение. Исходная страница берётся как основа независимо от видимости декоративных элементов редактора.

Все три API получают одно PNG и промпт. Маска отдельным изображением не отправляется: Koharu использует её для применения ответа. Восстановленный прямоугольник возвращается в координаты страницы; слой восстановления располагается под рисунком кистью. Автоматический клининг сохраняет нарисованные кистью пиксели, а применение ответа зависит от выбранного режима: вся страница или маска.

Локальное удаление создаёт отдельный Cleanup поверх растровых слоёв и изменяет только область маски. Предыдущие слои, их видимость и прозрачность сохраняются; следующее удаление видит уже нанесённый результат. Автоматический клининг тоже создаёт результат выше предыдущих растровых слоёв, чтобы повторный запуск был виден, сохраняя исключение пикселей Paint. Текст перевода остаётся отдельным редактируемым слоем и не включается в растровый вход LaMa.

## Соответствие предпросмотра запросу

Предпросмотр вызывается после общей подготовки изображения и обрезки. Для автоматического Fal-клининга в нём уже видна добавленная программой инструкция сохранения рисунка. После подтверждения правки промпта дополнительные инструкции не дописываются.

PNG предпросмотра кодируется из того же подготовленного изображения, которое получает клиент API. Код ожидающих запросов принадлежит приложению: остановка обработки, закрытие проекта и отмена ожидающего действия удаляют соответствующее окно; ответы привязаны к уникальному запросу.
