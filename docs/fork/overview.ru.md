# Форк Koharu коротко

Подробная версия для Claude лежит в [README.md](README.md).

## Как устроен `main`

С 18.10.2026 `main` собран из ветки `codex/upstream-editor-ocr` и честно слит (git merge) с оригиналом: сначала с версией 0.83.5, потом со свежим `main` оригинала на 18.10.2026. Следующая синхронизация делается так же, обычным merge.

Старый коммит `d1ebfef` с JEV, проверкой японского OCR, вариантами перевода под пузырь и цепочкой облачной очистки не собирался, поэтому в `main` его нет. Он остаётся в истории, и нужное из него возвращается отдельными PR, начиная с JEV.

## Что форк добавляет к оригиналу

- **OCR локально, через API или гибридно.** В гибридном режиме сначала локальный OCR проходит всю главу, потом нейросеть по API, и только потом перевод главы. Текст, который ты поправил руками, не перезаписывается.
- **Qwen OCR** как отдельный провайдер распознавания.
- **Облачная очистка картинки** через Fal, OpenRouter и Replicate, с предпросмотром и подтверждением результата.
- **Экспорт и импорт перевода главы.** Запрос сохраняется в JSON, его можно прогнать в любом чате и загрузить ответ обратно.
- **Именованные версии проекта**, ручной перевод, пресеты перевода главы, вставка текстовых блоков, дублирование страниц.
- **Обновления из релизов форка** `Projmix/koharu`.

## Что такое JEV

Это «судья»: внешний сервис, который отвечает не текстом, а выбором из готовых вариантов и вероятностью. Сейчас его в коде нет, он будет написан заново.

## План для OCR

1. Локальный OCR на всей главе: быстро и бесплатно. Уже работает.
2. Нейросеть по API читает те же фрагменты, видя черновик от локального OCR. Уже работает.
3. JEV сравнивает оба результата и выбирает лучший или говорит, что нужен человек. Это следующий шаг.
4. Блоки, где никто не справился (рукописный текст, необычные шрифты, разногласия), помечаются, и в редакторе их можно быстро найти и поправить.

## Что ещё важно

- Удалён браузерный макет `web-tauri-shim.ts`: он подменял приложение фейковыми данными, чтобы интерфейс открывался в обычном браузере, и для десктопа не нужен.
- Файл `protocol.ts` пришлось слить вручную. На своём компьютере стоит один раз запустить `cargo run -p koharu-app --bin generate` и закоммитить разницу, если она будет.
